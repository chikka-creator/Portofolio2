# A11Y.md — Kontrak Aksesibilitas (Farline rebuild)

Status: BERLAKU. Wajib diikuti untuk semua komponen.

## 1. Prinsip
- Canvas/container 3D buta untuk screen reader & tanpa-JS → setiap container punya padanan semantik (sr-only list judul + link).
- Reduced motion mematikan gerak, bukan tampilan. Posisi akhir identik dengan versi beranimasi.
- Elemen interaktif punya `aria-label` (tombol ikon) dan `:focus-visible` terlihat.
- Tidak ada informasi yang hanya disampaikan via warna.

## 2. Kontras
- Teks body ≥ 4.5:1 di atas putih → gunakan `#6B6A63` (muted-2) untuk teks kecil.
- `#969696` (muted) hanya untuk teks ≥ 18px atau uppercase mono (dekoratif/label).
- Ink `#14130E` untuk heading & teks utama.

## 3. Keyboard
- Semua elemen interaktif fokus via Tab.
- Enter/Space mengaktifkan button/link.
- Esc menutup dialog/lightbox/plate terbuka.
- Arrow keys navigasi plate (Home), filter (Gallery).
- Focus trap di dialog (native `<dialog>` + showModal menangani).
- Focus return ke pemicu saat dialog ditutup (manual `trigger.focus()`).

## 4. Screen reader
- `aria-label` pada container 3D: "Fakhri — a hang of prints. Use arrow keys to move along the line."
- `aria-current="page"` pada nav link aktif.
- `role="status"` pada status pill.
- `role="group" aria-label="Language"` pada lang toggle; `aria-pressed` pada tombol.
- `role="toolbar" aria-label="Filter"` pada filter bar; `aria-pressed` pada chip.
- `aria-live="polite"` pada error message form.
- `alt` deskriptif pada semua gambar (bukan kosong).

## 5. Focus visible
```css
:focus-visible {
  outline: 2px solid #14130E;
  outline-offset: 2px;
}
```
Jangan hapus outline. Jangan gunakan `outline: none` tanpa pengganti.

## 6. Reduced motion
```css
@media (prefers-reduced-motion: reduce) {
  .page-intro, .hang-plate, .gal-item { animation: none; transition: none; }
  /* state snap di JS */
}
```
JS: `const reduceMotion = matchMedia('(prefers-reduced-motion: reduce)').matches;` → flag global `window.__reduceMotion`. Semua lerp/inertia/float/parallax dicek flag ini.

## 7. Mobile touch
- `touch-action: pan-y` di container 3D (Home/About/Contact) agar scroll tidak kesedot.
- Gallery light table: `touch-action: none` (drag intentional) + pinch zoom.
- Target sentuh minimal 44×44px (chip, button, nav link).

## 8. No-JS fallback
- sr-only list judul + link terbaca.
- Form submit default (mailto) tetap jalan tanpa JS.
- Plate list DOM tampil bila canvas gagal.
