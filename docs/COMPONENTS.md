## 7. Konvensi umum
- Semua class prefix per halaman: `hang-`, `work-`, `gal-`, `about-`, `contact-`, `chrome-`.
- Tidak ada inline style kecuali nilai dinamis via CSS variable.
- Tidak ada inline script.
- Setiap canvas/container 3D punya padanan `.sr-only`.
- Gambar: `alt` deskriptif, `loading="lazy"` kecuali plate pertama Home, `draggable="false"` pada plate.
- Form input: `<label for>` atau wrapping label.
