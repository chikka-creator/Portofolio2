# Portofolio — Fakhri Cahyo Diandra Nandito

Personal portfolio, rebuilt in the style of Farline (https://farline.framer.website): white editorial, 3D hang hero, light-table gallery, glass nav.

## Status
Rebuild in progress. Spec: `FARLINE-SPEC.md`. Contract: `design.md`.

## Target structure (planned)
- `index.html` — Home with 3D hang hero (10 plates)
- `work.html` — Work index with hover preview
- `gallery.html` — Light-table gallery (11 certificates)
- `about.html` — About + experience
- `contact.html` — Contact + glass form (mailto)
- Shared shell: logo pill, status pill, glass bottom nav, ID/EN toggle

## Stack
- Static HTML/CSS/JS, zero build, zero npm.
- CSS 3D (`transform-style: preserve-3d`) + vanilla JS lerp.
- Fonts: Anton, Geist, Geist Mono (WOFF2).
- No Three.js, no Tailwind, no GSAP.

## Run (current legacy site)
Open `index.html` in a browser, or:
```bash
python -m http.server 8000
```
