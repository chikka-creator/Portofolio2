# I18N.md — Dictionary & Aturan (Farline rebuild)

Status: BERLAKU. Sumber tunggal untuk key i18n dan aturan penerjemahan.

## 1. Aturan
- Teks yang di-draw ke canvas/plate harus language-neutral (nama project/sertif). Lihat ORBIT_PLATES (title/tag tidak diterjemahkan).
- Teks berbahasa → `data-i18n="key"` (textContent) atau `data-i18n-html="key"` (innerHTML).
- Guard wajib: `if (translations[currentLang][key])` sebelum apply.
- Key mati boleh (contoh `navCert`), teks tanpa key tidak boleh.
- Kolom baru wajib diisi dua sisi (id + en).
- Teks berisi HTML → `innerHTML`; teks biasa → `textContent`.
- HUD yang berganti per state memakai hook `updateHUDLanguage()`.
- Persist pilihan: `localStorage.lang` (default `id`).
